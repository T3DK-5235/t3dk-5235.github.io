ABOUT
Hi! I'm Joseph Sosin, a games programmer from the UK. I am currently studying for a Games Programming masters degree, following my Computer Science bachelors degree. Alongside these curriculums, starting back in my undergraduate, I have taught myself the Unity, Godot and Unreal game engines. This self study included teaching myself C#, as well as learning web languages, such as CSS, Javascript and HTML.
PROJECTS
Buckshot Demake

Created in a custom engine with C++, OpenGl and SDL, this project was the product of a University assignment with the prompt of creating a demake of a modern game. I chose to demake the popular, at the time, game, Buckshot Roulette.

This included features such as near random shell selection (with saveguards to prevent all live or all blank rounds), an audio system using CC0 audio, and AI logic.

One
SCP: Administration

This was first created during my undergraduate degree as a sandbox project. I iterated over this project regularly, tweaking code to fit with new knowledge I had gained.

The project's frontend focuses primarily on UI interaction, enabling me to test various elements independent from the engine itself. I aimed to present this publicly on itch.io as it allowed me to set a series of deadlines to structure my work.

Two
Temporal Shift

This game was a group project created during my masters program. The game was inspired by gravity mechanics from Super Mario Galaxy and Outer Wilds, as well as time shift mechanics used in games like Titanfall 2.

I was primarily involved with the gravity system, the player pickup system, and in world interactable elements, such as buttons, item spawners, and moving platforms. Working with variable gravity direction was new to me and created lots of interesting problems.

Three
Unreal Engine - Lyra Project

During this project I learnt how unreals plugin system worked and how to use it to interface with an existing project.

My focus for this project was pathing AI and player positioning. I used AIs that moved along a path to force players to interact with each other more and avoid situations where players could stay in the same area, creating frustration or boredom.
